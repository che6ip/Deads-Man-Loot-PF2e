# Dead's Man Loot — Pathfinder 2e

Адаптер **Pathfinder 2e** для базового модуля **Dead's Man Loot** (`deads-man-loot`).

Передаёт базе системные значения PF2e: какие предметы материальны, сколько их, какая у них
редкость и уровень, а также когда существо считается мёртвым.

## Возможности

- Определяет материальные предметы PF2e и исключает заклинания, действия, способности, состояния,
  эффекты и другие нематериальные типы.
- Считает количество, редкость и уровень предметов.
- Распознаёт смерть по флагу `isDead`, состоянию «Мёртв», эффектам, посмертным статусам токена и
  нулю хитов.
- Добавляет поле **«Шанс дропа»** в карточку предмета (только для Мастера).
- Поддерживает мешочки монет с формулами в описании предмета.

## Установка

1. Установите и включите базовый модуль **deads-man-loot**.
2. Скопируйте папку `deads-man-loot-pf2e` в `Data/modules/deads-man-loot-pf2e`.
3. Включите адаптер в настройках мира (**Manage Modules**).
4. Обновите сцену клавишей **F5**.

Требуется система **Pathfinder 2e 6.0+** и активный Мастер.

## Как пользоваться

1. Откройте карточку предмета — поле **«Шанс дропа»** находится рядом с ценой или в боковой
   панели. Задайте значение от 0 до 100%.
2. Доведите существо до 0 хитов или повесьте состояние «Мёртв».
3. Дважды кликните по трупу — откроется окно добычи.
4. Нажмите **«Взять»**, чтобы перенести предмет своему персонажу.
5. ПКМ по предмету открывает его карточку.

В окне добычи у предметов PF2e также показывается уровень.

## Настройки

Собственных настроек у адаптера нет. Все параметры добычи и отображения шансов находятся в
базовом модуле **Dead's Man Loot**.

## Совместимость

- Foundry VTT **13+** (проверено на сборке 14.369).
- Pathfinder 2e **6.0+**.
- Требуется базовый модуль **deads-man-loot 1.0.0+**.
- Для игроков нужен активный Мастер.
